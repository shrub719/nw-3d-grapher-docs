## 5.3 Areas for improvement

A small addition to the grapher display would be to add labels to the axes
which rotate with the graph to make domain display more intuitive. 
This requires a rather difficult interface with the
frame buffer structure, possibly including the need for graphical assets to be compiled with the
program, but would mirror the UX of other popular 3D graphing programs.

Support for parametric equations is also limited if they cannot be redefined as implicit locii.
Allowing graphs to be defined in terms of a parameter would be a useful expansion to the program that 
encompasses more of the A level specification.

Furthermore, the ability to trace a graph - perhaps using a new mode similar to VIEW and DOMAIN -
would allow more in detail analysis of graph properties, one of the intended goals of the program.

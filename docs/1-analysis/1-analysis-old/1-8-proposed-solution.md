## 1.8 Proposed solution

This project aims to streamline the use of 3D graphs in a classrom environment; therefore, my proposed solution is a third-party app for the NumWorks calculator written in C++. This app is able to take implicit and explicit equations like the NumWorks Grapher and display them similar to the fx-CG50's 3D Graph program.

This balances performance on embedded hardware with accessibility to students, by implementing a new feature seamlessly into a teaching tool.

# 1. Analysis

The NumWorks calculator is a graphing calculator designed with the senior
mathematics student in mind. It has an accessible user interface, and attempts
to be as feature complete as possible for senior exams like A level mathematics,
including a certification for being exam sanctioned internationally.

As such, the calculator is equipped with several applications, including Grapher,
a graphing app similar in functionality to Desmos Graphing, but built for the
restricted hardware of a calculator to be used in official examinations.

In addition, NumWorks' mission aims to make the calculator as easy to use for teachers
to faciliate a learning environment in classrooms, with easily presentable features
and a simulator for the calculator's OS which allows students to follow what teachers
are doing on-screen.

My project revolves around the function of the NumWorks calculator, and where it falls
short; 3D graphing is entirely unavailable, as I discuss within this analysis, yet
many exams worldwide - specifically the GCE Further Maths qualification from
several exam boards in the UK, which are the focus of my target market - require it
in exams.
